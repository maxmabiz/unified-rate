# 统一汇率

FUND 资金中台 · 统一汇率管理前端原型（React + TypeScript + Ant Design）。Mock 数据，不接真实 Reuters。

## 在线演示

GitHub Pages：https://maxmabiz.github.io/unified-rate/

当前版本：v0.1.0（2026-08-18）

## 本地预览

```bash
npm install
npm run dev
```

访问 http://127.0.0.1:5173/unified-rate/data

推送到 `main` 后会自动部署 GitHub Pages。
